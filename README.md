# AutoGraderLM
Automatic LLM-based Grader for Homework Grading

## Quick Start

```bash
conda create -n autograder python=3.12
conda activate autograder
pip install -r requirements.txt
```

## Requirements

### Backend

- LangGraph: pipeline buildup
- LangSmith: trace and debug monitor
- FastAPI: for WebUI
